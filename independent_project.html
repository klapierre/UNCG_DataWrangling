Project Overview


Experimental Backround The dataset that I chose is from the study by Kehrberger & Holzschuh (2019), which looked at how the timing of flowering influences pollinator interactions and reproductive success in the plant Primrose (Primula vulgaris). The phenology can have a strong impact on plant reproduction because flowering timing determines pollinator availability and competition. The primary goal of this study was to determine how flowering abundance, pollinator visitation rates, and environmental factors vary throughout a flowering season, and then how these factors are related to reproductive success. Data was collected across the 2015 flowering season for P. vulgaris. Site-level data was recorded daily and weekly to track flower abundance, pollinator activity, and environmental conditions. Individual flowers were also monitored for bud opening, pollination, and reproductive success. Two experimental treatments were also done, controlling pollination limitation and means of pollination.

Data Structure Within the dataset, there are five data sheets with different coverage. The first sheet, T1, includes daily site-level observations at each site during surveying. It includes information about the flowering abundance of P. vulgaris, flowering abundance of other species, pollinator visitation rates, and temperature. The second sheet, T2, contains weekly summaries of flowering abundances, visitation rates, and bee abundance. The third sheet, T3, contains measurements taken from individual P. vulgaris flowers, including bud opening date, floral longevity, suitable pollinator hours per flower, seed set, floral mean temperature, and estimated visitation. T4 contains data for the pollen limitation experiment, and the resulting seed set percentage (reproductive success). T5 contains data for the pollen treatment experiment, like the treatment (naturally pollinated or hand pollinated), bud opening date, and seed set.

Kehrberger, S., & Holzschuh, A. (2019). How does timing of flowering affect competition for pollinators, flower visitation and seed set in an early spring grassland plant? Scientific Reports, 9(1), 15593. https://doi.org/10.1038/s41598-019-51916-0

T4 has a really nasty outlier that’ll interfere with our statistics, lets remove it!

Q1 <- quantile(T4$pollen_limitation, 0.25, na.rm = T)
Q3 <- quantile(T4$pollen_limitation, 0.75, na.rm = T)
IQR <- Q3 - Q1

T4 <- T4 %>% 
  filter(pollen_limitation >= (Q1 - 1.5 * IQR) & pollen_limitation <= (Q3 + 1.5 * IQR)
         )

Visualization

Visualize flowering abundance over time using gganimate.

  • Color by site.
  • Reveal the graph by date (x-axis).
(plot_T1_time <- T1 %>% 
   ggplot(aes(x = date,
              y = flower_count,
              color = site,
              group = site)) +
   geom_line(alpha = 0.9) +
   theme_bw() +
   labs(title = "Flowering Abundance over Time",
        x = "Date",
        y = "Flower Count",
        color = "Site") +
   transition_reveal(date)
 )

Figure 1. The amount of Primula vulgaris flowers sharply increases across most sites around late March and begins to fall off around mid April. This line’s up with the approximately three week flowering period that is expected for this species.

Visualize the relationship between flower abundance and bee visitation.

  • Color by site.
  • Apply log+1 scaling to visitation_rate.
    • These values are too small to accurately visualize trends.
(plot_T1_visitation <- T1 %>% 
    ggplot(aes(x = flower_count,
               y = log1p(visitation_rate),
               color = site)) +
    geom_jitter(alpha = 0.4, height = 0.01, width = 5) +
    theme_bw() +
    labs(title = "Flower Abundance versus Bee Visitation",
         x = "Flower Count",
         y = "log(Visitation Rate + 1)",
         color = "Site")
  )

Figure 2. Flower count and bee visitation rate appear to have a negative relationship, when only looking at values that aren’t highly clustered due to extremely small visitation rates. This relationship appears very weak, though.

Visualize bee abundance over time across each site.

  • Color by site.
  • Apply bin scaling to the x-axis to make weeks discrete.
(plot_T2 <- T2 %>% 
    ggplot(aes(x = week,
               y = bee_abundance,
               color = site)) +
    geom_line() + 
    geom_point(size = 0.8, alpha = 0.8) +
    theme_bw() +
    scale_x_binned(expand = c(0, 0)) +
    labs(title = "Weekly Bee Abundance Across Sites",
         x = "Week",
         y  = "Bee Abundance",
         color = "Site")
  )

Figure 3. Bee abundance fluctuates weekly across most sites, with a distinctly elevated amounts between weeks 13 through 16, which aligns with the flowering period of Primula vulgaris. Site’s 1 and 3 also experienced heavy peaks around week 18, which is likely attributed to other flowering species. These other species are accounted for in this dataset, but not this manipulation.

Visualize the relationship between Bee Visitation and Seed Set %.

  • Color by site.
  • Smooth trends using a linear model.
(plot_T3 <- T3 %>% 
    ggplot(aes(x = bee_visits,
               y = seed_set,
               color = site)) +
    geom_point(alpha = 0.4) +
    geom_smooth(method = "lm", se = F, linetype = "dashed") + 
    theme_bw() +
    labs(title = "Bee Visits versus Seed Set",
         x = "Bee Visits",
         y = "Seed Set (%)",
         color = "Site")
  )

Figure 4. Bee visitation is loosely positively related with seed set across most sites and negatively at site 4, which has fewer observations. The positive relationship is expetced, as these flowers rely on insect pollination to produce seeds. Several individuals have high seed set but low bee visitation, which is likely explained by non-bee pollinators or bees that were not observed (observer bias).

Visualize the relationship between Pollen Limitation and Seed Set %.

  • Smooth trends using a linear model.
  • Add the equation and p-value of the lm using ggpmisc’s stat_poly_eq().
(plot_T4 <- T4 %>% 
    ggplot(aes(x = pollen_limitation,
               y = seed_set)) +
    geom_jitter(alpha = 0.5, width = 0.2) +
    geom_smooth(method = "lm", se = F) +
    theme_bw() +
    labs(title = "Pollen Limitation Effect on Seed Set",
         x = "Pollen Limitation",
         y = "Seed Set (%)") +
    stat_poly_eq(aes(label = paste(..eq.label.., 
                                   ..p.value.label.., 
                                   sep = "~")))
)

Figure 5. As the rate of pollen limitation increases, the percentage seed set significantly decreases at 19.6% per unit (**, p = 0.002).

Visualize the results of each pollination treatment on Seed Set %.

  • Add p-values using ggpubr’s stat_compare_means().
(plot_T5 <- T5 %>% 
    ggplot(aes(x = treatment,
               y = seed_set,
               fill = treatment)) +
    geom_boxplot() +
    theme_bw() +
    labs(title = "Seed Set by Pollination Treatment",
         x = "Treatment",
         y = "Seed Set (%)") +
    theme(legend.position = "none") +
    stat_compare_means(method = "t.test", 
                       label = "p.format", 
                       comparisons = list(
                         c("hand", "open"),
                         c("hand", "pollinator exclusion"),
                         c("open", "pollinator exclusion")
                       ))
  )

Figure 6. The percentage seed set between the hand pollinated control, open to pollinators treatment, and the pollinator exclusion treatment. The difference between the control and open treatment was not significantly different (p = 0.66). The difference between the control and the pollinator exclusion treatment was highly significantly different (****, p = 6.6e-15). The difference between the open treatment and the pollinator exclusion treatment were also significantly different (***, p = 2.4e-14).
